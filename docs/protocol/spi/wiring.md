# SPI — wiring and electrical requirements

Part of the SPI documentation set (`docs/protocol/spi/`). This page owns the
wiring table, the pull-up and supply rules, the VPU route, the voltage limit,
and the pin names used by the `v` display. The README carries the headline
only; entry and bring-up are in [entry-and-setup.md](entry-and-setup.md).

## Wiring

SPI is a four-wire bus plus ground. The Bus Pirate's header uses the same
signal names:

| Bus Pirate pin | Direction | Target connection | Description |
|---|---|---|---|
| MOSI | → | MOSI | Master Out, Slave In — data from the Bus Pirate |
| MISO | ← | MISO | Master In, Slave Out — data into the Bus Pirate |
| CS | → | CS | Chip select / slave select |
| CLK | → | CLK | Clock, generated by the Bus Pirate |
| GND | ⏚ | GND | Signal ground, common with the target |

In the master modes (terminal and binary) the Bus Pirate drives CS, CLK and
MOSI and reads MISO. In **sniffer** mode the roles change — all four pins
become inputs (see §Sniffer wiring). The dedicated CS pin is the one the mode
drives. The `c`/`C` AUX assignment can point `a`/`A`/`@` at the same CS pin; do
not drive CS from both the AUX commands and the SPI CS commands.

## Pin names in `v`

The `v` table names the SPI pins in its last four signal columns. The order
differs between boards:

| Build | Last four columns (left to right) |
|---|---|
| v4 | `CS` `MISO` `CLK` `MOSI` |
| v3 | `CLK` `MOSI` `CS` `MISO` |

The preceding columns are the fixed grounds, rails and AUX columns. The
firmware separates columns with tab characters, so the spacing of raw terminal
output depends on the terminal's tab stops; the table above is the reliable
content.

`v` reports the pin direction in its direction row (`I` input, `O` output,
`P` power/analogue) and the level in the row below; the direction alone does
not tell you the high level. An open-drain output still shows `O` while its
high level is high impedance. If `v` shows `I` for CS, CLK and MOSI in SPI
mode, the bus is not engaged: run `W` (or run it again after `w`).

## Pull-up and supply requirements

**The pull-up requirement follows the output type chosen during setup.** There
is no single answer for the mode:

| Output type | High level | Pull-up | Typical use |
|---|---|---|---|
| `Open drain (H=Hi-Z, L=GND)` — the default | high impedance, set by the pull-up | **required** | 5 V or mixed-voltage buses, shared buses |
| `Normal (H=3.3V, L=GND)` — option 2 | driven 3.3 V | **none** | 3.3 V point-to-point |

In open-drain output the Bus Pirate only pulls lines low. Every high level on
CS, CLK and MOSI comes from the pull-up, so fit **one pull-up per output line**
— the on-board pull-ups switched by `P`, or external resistors of
**2 kΩ – 10 kΩ** to the target's logic rail. Without a pull-up the high level
floats; a target can see a stuck-low clock or a permanently asserted CS.

MISO is an input and is driven by the target when it is selected. It does not
need a Bus Pirate pull-up for the Bus Pirate's sake; if the target tri-states
MISO, the bus needs its own pull-up or the read value floats.

Normal output drives 3.3 V high itself and needs no pull-up. It **cannot
produce a 5 V high**; for a 5 V bus use open drain with the pull-up rail at
5 V. Do not use normal output to drive a line that another device is already
driving.

### The pull-up reference: Vpullup

The pull-up resistors connect the I/O lines to the physical **Vpullup** pin —
the pin marked `Vpu` on the reference card ("input pull-up resistors 0–5 V");
the `v` table calls its column `VPU`. The firmware calls the pin "Vpullup".

- **v4** — `e1` selects External (or None), `e2` routes the on-board **3.3 V**
  rail, and `e3` routes the on-board **5.0 V** rail. Selecting a source is
  allowed only in a non-HiZ mode whose pins are open-drain high impedance and
  with no voltage already on Vpullup.
- **v3** — there is no `e`; feed the `Vpu` pin from an external 0–5 V supply.

**Set Vpullup to the target's logic supply.** A 5 V pull-up on a 3.3 V target
can damage it: on v4 use `e2` for a 3.3 V target and `e3` only for a 5 V
target, or feed `Vpu` externally at the target's voltage. The 3.3 V and 5.0 V
pins that `W` enables are the **target supply**; Vpullup is the separate
pull-up reference, and it does not power the target.

`P` enables the on-board pull-ups. A voltage must be present on Vpullup for
them to pull high; without one, `P` still enables them and prints
`Warning: no voltage on Vpullup pin`. The `P`/`e` commands and the VPU route
are base-layer behaviour owned by [docs/generic/](../../generic/commands.md);
this page records only the SPI requirement.

### Bring-up order with the on-board pull-ups (v4)

1. Wire the target with its supply off.
2. Enter SPI and answer `Select output type:` with open drain. `e` is
   refused in Normal output.
3. Run `e2` for a 3.3 V target or `e3` for a 5 V target. `e` is refused
   while Vpullup already has a voltage.
4. Run `W` to switch on the rails and run the SPI pin setup. `W` is required
   even when the target is self-powered.
5. Run `P` to connect the pull-up resistors. With an on-board source selected
   and `W` on, Vpullup has a voltage and `P` does not warn.
6. Check `v`; in open drain the lines show `O`, and the high level comes from
   Vpullup.

For an external Vpullup feed, select `e1` before connecting the feed; `e`
refuses while the pin already has a voltage. The same order applies on v3
without step 3: wire, `W`, then `P`, with `Vpu` fed externally before `P`.

### Target supply

The target supply is separate from Vpullup:

- `W` enables the on-board regulator and puts the **3.3 V** and **5.0 V**
  rails on their header pins. Connect the target's VCC to the rail it needs —
  never both — or leave both disconnected for a self-powered target.
- `W` also runs the SPI pin and module setup. It is required even when the
  target is self-powered; the success check reads the Bus Pirate's own rails,
  not the target's supply.
- `w` switches the rails off and releases the SPI pins to inputs.
- Vpullup only sets the pull-up reference. It does not power the target.

Do not back-drive a rail that is switched off, and keep the target ground
common with the Bus Pirate.

## Voltage limit

The SPI interface is **5 V safe**; do not exceed **5.5 V** on any signal pin.
Vpullup is a 0–5 V input.

## Sniffer wiring

The sniffer is input-only and does not use the Bus Pirate's target supply:

- Connect **GND** common and all four signals: CS, CLK, MOSI and MISO.
- Power the target from its own system. Do not connect the Bus Pirate's
  3.3 V/5.0 V rails to a live target. The sniffer does not switch the target
  supply on or off; if you ran `W`, the rails stay on.
- The sniffed bus needs whatever pull-ups its normal operation requires. If it
  is open-drain and has none, enable the Bus Pirate pull-ups with `P` and feed
  Vpullup, or fit external 2 kΩ – 10 kΩ resistors. The sniffer itself only
  listens.
- Enter the sniffer **before** connecting the target; the master configuration
  **can** drive CS, CLK and MOSI until the sniffer macro runs.
- Stop the sniffer only when the external master is quiet. Exit runs the
  master pin/module setup, so CLK, MOSI and CS become outputs; it does not
  restore the previous input state and does not switch the target supply.

The full procedure and the capture limits are in [sniffer.md](sniffer.md).

## Edge cases

| Trigger | Symptom | Behaviour / recovery |
|---|---|---|
| Open drain with no pull-up | CS/CLK/MOSI float; the target may see a stuck-low clock or asserted CS | fit 2 kΩ – 10 kΩ to the target rail, enable `P` with Vpullup fed, or select Normal output |
| Vpullup is set to 5 V for a 3.3 V target | the pull-ups put 5 V on CS/CLK/MOSI | use `e2` for 3.3 V, `e3` only for 5 V, or feed `Vpu` at 3.3 V |
| `P` with no voltage on Vpullup | `Warning: no voltage on Vpullup pin`; the pull-ups do not pull high | `e2`/`e3`, `W`, then `P` on v4; external `Vpu` on v3 |
| Normal output on a 5 V bus | the high level is 3.3 V; the target may not accept it | use open drain with Vpullup at 5 V |
| Active-high `CS` selected with open drain | the asserted level is high impedance and depends on the pull-up | fit the pull-up or use Normal output |
| MISO floating | reads return `0x00`, `0xFF` or noise | the target must drive MISO when selected, or the bus needs a pull-up |
| More than 5.5 V on a signal | damage risk | stay within 5 V safe / 5.5 V maximum |
| `v` shows `O` but the line is not driven high | open-drain high is high impedance | that is expected; the pull-up sets the high level |

## v3 / v4

| Item | v3 | v4 |
|---|---|---|
| CS / CLK / MOSI pins | outputs | outputs |
| MISO pin | input | input |
| pull-up required | open-drain output only | open-drain output only |
| VPU source selection | none — feed `Vpu` externally | `e1` / `e2` / `e3` |
| `v` signal-column order | `CLK` `MOSI` `CS` `MISO` | `CS` `MISO` `CLK` `MOSI` |
| target supply via `W` | same | same |

The v3 column is **not verified**.
