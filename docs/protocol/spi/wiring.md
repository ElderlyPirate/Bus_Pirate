# SPI — wiring and electrical requirements

Part of the SPI documentation set (`docs/protocol/spi/`). This page owns the
wiring table and the pull-up/supply statement; the README carries the headline
only.

## Wiring

SPI is a four-wire bus plus ground. The Bus Pirate's pins use the same labels
as the signals:

| Bus Pirate pin | Direction | Circuit | Description |
|---|---|---|---|
| MOSI | → | MOSI | Master Out, Slave In — data from the Bus Pirate |
| MISO | ← | MISO | Master In, Slave Out — data into the Bus Pirate |
| CS | → | CS | Chip Select / slave select |
| CLK | → | CLK | Clock, generated by the Bus Pirate |
| GND | ⏚ | GND | Signal ground, common with the target |

The Bus Pirate is always the master: it drives CLK, MOSI and CS, and reads
MISO. In **sniffer** mode the roles change — all four pins become inputs (see
[sniffer.md](sniffer.md)).

Pins are named `CS`, `MOSI`, `MISO` and `CLK` throughout this set. The `v`
pin-state display prints the four labels in a different order on the two
boards (`CS MISO CLK MOSI` on v4, `CLK MOSI CS MISO` on v3); the names are the
same.

## Pull-up and supply requirements

The pull-up rule follows the **output type** chosen during setup
([entry-and-setup.md](entry-and-setup.md)):

| Output type | High level | Pull-up |
|---|---|---|
| `Open drain (H=Hi-Z, L=GND)` — the default | Hi-Z (from the pull-up) | **pull-up required** |
| `Normal (H=3.3V, L=GND)` — option 2 | driven 3.3 V | **no pull-up needed** |

Only the open-drain type leaves the outputs high-impedance; the normal type
drives the outputs high itself, so it does not need a pull-up. Because the
firmware defaults to open-drain, an **unanswered** setup chain leaves the mode
needing a pull-up; select option `2` to run without one.

For open-drain operation, fit pull-up resistors of **2 kΩ – 10 kΩ** from
each open-drain output line to the pull-up voltage. Open drain with pull-ups
is the way to interface a target that runs at a different voltage, because
the Bus Pirate only pulls lines low.

The Bus Pirate's own pull-up resistors are connected to the physical
**Vpullup** pin (`Vpu`). They are switched with `P`/`p`; a voltage must be
present on that pin for them to pull high. Without one, `P` still enables the
resistors and prints `Warning: no voltage on Vpullup pin`.

The source that feeds VPU is selected per build:

- **v4** — `e2` selects the on-board **3.3 V** source and `e3` the on-board
  **5.0 V** source; `e1` is External (or None). Selecting a source is only
  allowed while the pins are open-drain HiZ and no voltage is already on VPU.
- **v3** — there is no `e`; feed the Vpullup pin from an external 0–5 V
  supply.

The target's own supply (VCC) is separate from VPU: `W` enables the Bus
Pirate's programmable supply on the VCC pin to power the target, while VPU
only sets the pull-up reference. `W` also runs the mode's pin and module
setup — the bus is not configured until `W` succeeds, so `W` is required
even when the target is self-powered (leave VCC disconnected in that case).

The `P`/`e` commands and the VPU routing are base-layer behaviour owned by
`docs/generic/` (see [commands.md](../../generic/commands.md)); this page
records only that **SPI needs a pull-up in open-drain output and none in
normal output**.

## Voltage limit

The SPI interface is 5 V safe; do not exceed **5.5 V** on any signal pin.

## v3 / v4

| | v3 | v4 |
|---|---|---|
| CS / MOSI / CLK pin | outputs | outputs |
| MISO pin | input | input |
| pull-up required | open-drain only | open-drain only |
| VPU source selection | none — feed externally | `e1` / `e2` / `e3` |
| `v` pin-label order | `CLK MOSI CS MISO` | `CS MISO CLK MOSI` |

v3 wiring and the v3 VPU route are **not verified**.
